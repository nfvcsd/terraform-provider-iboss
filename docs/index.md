# iboss Provider

The iboss provider manages configuration of the iboss Zero Trust SSE platform through the
[iboss API](https://documenter.getpostman.com/view/26524233/2s93RUuXjk). It is maintained by
North Fayette Valley Community School District and is not affiliated with or endorsed by iboss or
HashiCorp.

~> **Provided as is.** This provider is provided "as is", without warranty of any kind. North Fayette
Valley Community School District is not responsible for any damage arising from its use. See the
[license](https://github.com/nfvcsd/terraform-provider-iboss/blob/main/LICENSE) (MPL-2.0, sections 6
and 7). Test changes on a non-production security group first.

The current release covers gateway **URL allowlists and block lists** per security (filtering) group,
plus the lookups needed to target them. See
[`docs/api-coverage.md`](https://github.com/nfvcsd/terraform-provider-iboss/blob/main/docs/api-coverage.md)
for what is and is not implemented.

## Example Usage

```terraform
terraform {
  required_providers {
    iboss = {
      source = "nfvcsd/iboss"
    }
  }
}

# Recommended: API key authentication. Supply the key through the
# IBOSS_API_KEY environment variable (for example from your CI secret store)
# rather than writing it in configuration.
provider "iboss" {}

# Optional: pin the account and gateway instead of discovering them.
# provider "iboss" {
#   account_settings_id = 123456
#   gateway_host        = "cn-0000000000-00-example.ibosscloud.com"
# }
```

## Authentication

Choose exactly one method. The provider never falls back from one to the other.

| Method | Arguments | Environment variables |
|---|---|---|
| API key (recommended) | `api_key` | `IBOSS_API_KEY` |
| Legacy session login | `username`, `password`, optional `totp_code` | `IBOSS_USERNAME`, `IBOSS_PASSWORD`, `IBOSS_TOTP_CODE` |

If any credential argument is set in the `provider` block, the credential environment variables are
ignored. Setting both an API key and a username/password is an error.

A TOTP code is single-use. With MFA enabled, a legacy session that expires mid-run cannot be renewed
automatically; prefer an API key for unattended runs.

### What the provider does on first use

1. API key: sends `Authorization: Token <key>`. Legacy: calls `accounts.iboss.com` (or `accounts_host`) with
   HTTP Basic authentication to obtain a session token.
2. Calls `api.ibosscloud.com` to find the account (the primary account unless `account_settings_id` is set)
   and to obtain the session cookies the gateway API expects.
3. Unless `gateway_host` is set, discovers the primary gateway node from the account's node clusters. A
   discovered host must be a plain host name under `ibosscloud.com`; anything else is rejected before
   credentials are sent to it. Redirects are never followed.

Credentials and session tokens are never written to Terraform state.

## Limitations

- List entries have no documented update operation, so changing any argument replaces the entry.
- Timed (expiring) entries are not supported by the resources.
- The bulk "replace list" endpoints are not used; resources manage individual entries and leave other
  entries alone.
- The provider is tested only against a local simulator built from the published documentation. Validate
  changes in a non-production iboss group before broad rollout.

## Schema

### Optional

- `account_settings_id` (Number) iboss account settings ID. When omitted, the provider discovers the primary account (the one with no delegated super admin). Falls back to `IBOSS_ACCOUNT_SETTINGS_ID`.
- `accounts_host` (String) Host name used for legacy username/password login. Defaults to `accounts.iboss.com`. Only needed if iboss directs you to a different login host. Falls back to `IBOSS_ACCOUNTS_HOST`.
- `api_key` (String, Sensitive) iboss API key, sent as `Authorization: Token <key>`. Conflicts with `username`/`password`. Falls back to `IBOSS_API_KEY`.
- `gateway_host` (String) Host name of the primary gateway node (for example `cn-0000.ibosscloud.com`). When omitted, it is discovered from the account's node clusters. Falls back to `IBOSS_GATEWAY_HOST`.
- `password` (String, Sensitive) Administrator password for legacy session login. Falls back to `IBOSS_PASSWORD`.
- `totp_code` (String, Sensitive) One-time MFA code for legacy login when MFA is enabled. A code is single-use, so a session that expires mid-run cannot be renewed automatically. Falls back to `IBOSS_TOTP_CODE`.
- `username` (String) Administrator username for legacy session login. Requires `password`. Falls back to `IBOSS_USERNAME`.
